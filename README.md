# Проект ДЗ 10 марта

Основные команды гита:
1. cd "адрес папки на компьютере"
   git clone ссылка с гита
2. Когда вносим изменения:
   ```
   git add название файла 
   ```
3. Добавить комментарий человеческим язык ом
   ```
   git commit -m ''
   ```
4. Отправить изменения на сервер (ветка main)
   ```
   git push origin main
   ```
